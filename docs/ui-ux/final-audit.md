# Phase 2 — Command Deck × Terminal IDE hybrid (approved redesign)

Direction approved by user: **A (Command Deck) base + B (Terminal IDE) touches**,
plus a specified motion layer. No backend/API/business-logic changes.

## What changed visually

- **Hero** (`components/Hero.tsx`): split composition — oversized two-line headline,
  mono kicker, CTA row with `kbd` hints, vitals stat strip, and a live "intake
  console" card (window chrome, staggered terminal-line reveal, blinking caret,
  animated confidence meter blocks, pulsing live dot).
- **Workspace** (`app/page.tsx`): flat cards replaced by a single raised
  `panel-card` instrument shell with title-bar chrome (traffic dots, console
  label, live status pip) and numbered mono section labels
  (`01 intake // symptoms`, `02 output // diagnosis`).
- **Form** (`components/DebugForm.tsx`, `ui/TextArea.tsx`): terminal-style mono
  field labels; broken-code input gets a synced, non-interactive line-number
  gutter (`wrap="off"`, `aria-hidden`, scroll-synced via transform).
- **Report** (`components/DiagnosisReport.tsx`): six numbered clinical rails
  (`01 diagnosis` … `06 prevention`) with mono `//` headers, `EXIT 0` badge +
  confidence metadata header, 50 ms-per-step staggered cascade (`report-step`).
- **States**: `LoadingDiagnosis` shows a cyan scanline sweeping a preview of the
  submitted code (`animate-scanline`, transform-only) above the simulated steps;
  `EmptyState`/`ErrorState` restyled to console chrome (`exit 1` marker, mono
  kickers, icon chips — emoji removed).
- **Copy Fix** (`components/CodeBlock.tsx`): checkmark pop (`check-pop`,
  transform/opacity) on success; deeper code-well chrome.
- **Header**: emoji logo replaced by a bordered Stethoscope brand mark.

## Motion spec compliance

- All keyframes animate `transform`/`opacity` only (GPU-composited):
  `fade-in-up` (reveal/report-step), `live-dot`, `caret-blink`, `scanline`,
  `check-pop`.
- Durations 0.22–0.4 s; cascade step = 50 ms as specified.
- `prefers-reduced-motion`: global kill-switch collapses all animation/transition
  durations to ~0 (verified: computed `animation-duration: 1e-05s`).
