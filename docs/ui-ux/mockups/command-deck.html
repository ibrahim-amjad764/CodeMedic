01 — SYMPTOM

Diagnosis

The program crashes with a TypeError because age is a string returned by input(), and age + 1 attempts to add an integer to a string.

02 — ROOT CAUSE

Root Cause

input() always returns str. Line 2 adds integer 1 to that string — Python has no implicit int→str coercion.

03 — EVIDENCE

Evidence

  • Error names the exact operation: 'int' and 'str'
  • age = input(...) binds a string
  • age + 1 mixes str + int
04 — TREATMENT

Treatment

Fixed Python
# Convert the input string to an integer first
age = int(input("Enter your age: "))
next_year = age + 1

print(next_year)
  • Wrapped input() in int()
05 — EXPLANATION

Why This Works

int() parses the typed text into a number before the addition runs, so age + 1 is now int + int — valid arithmetic.

06 — PREVENTION

Prevention

  • Always convert input() results before math
  • Validate with try/except ValueError for bad input
